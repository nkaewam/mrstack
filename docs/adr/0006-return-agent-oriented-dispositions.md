# Return agent-oriented dispositions

Every check will return one stable top-level disposition—`action_required`, `waiting`, `human_required`, `ready`, `complete`, or `invalid`—alongside typed findings and structured suggested actions. When findings coexist, precedence is `invalid`, `action_required`, `human_required`, `waiting`, `ready`, then `complete`; all lower-priority findings remain in the response. `ready` means healthy within `mrstack`'s deliberately limited scope—valid and aligned topology plus relevant CI—not a claim that approvals or every GitLab merge policy permit merging. This explicit control protocol lets an agent distinguish repairable work from polling and human intervention without interpreting prose, while detailed findings preserve the reasons behind the classification.
